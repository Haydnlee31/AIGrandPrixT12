# Editable intent and first-use discovery

Implemented on the iOS branch, 25 October 2026.

Update: the separate discovery entry and screen were removed at the user’s request because they duplicate Explore. Explore remains the recommendation surface; saved-product preference editing was subsequently removed in favor of photo-region capture. The discovery API below is retained but is no longer exposed by the iOS app.

## Saved product: What matters to you

The saved-product screen presents the confirmed preferences and an Edit sheet. Optional detail suggestions come from the existing image analysis (including detected dial/strap descriptions) and its contextual prompts. Nothing is selected merely because the model observed it. Users select/remove suggestions or edit one preference per line, including Brand flexible. Save uses the existing local library's grouped-product preference persistence, so original images, sources and notes are preserved. Cancel does not modify preferences. Find options for these details opens recommendations scoped to this product, using the newly saved preferences. Brand flexible removes the original-brand scoring boost. This version uses corresponding detail suggestions, not image-region segmentation or pixel tapping.

## Explore: Show me something interesting

No saved items are required. The authenticated `/v1/discover` endpoint selects up to four different product families from the enabled, sourced Amazon catalog. Every card has the catalog record's actual image and exact product URL. None of these sends the displayed IDs as dismissals, rotating the next choices. Selecting a card retrieves that product family; a tentative brief based on catalog title/category is editable. Explicit color/material preferences affect retrieval and ranking. Subsequent selections expose their own editable interpretation. All browsing preferences are session-only and do not change the user's Library or permanent profile. Product details retain source attribution, exact merchant link, and live price checking. When saves exist, discovery defaults to those interests: same-category matches show the matching detail and original save. Cross-category suggestions transfer only explicitly confirmed colors/materials, with wording such as "silver, inspired by the silver dial you liked." Actual catalog category and exact Amazon identity are required. Observed image details alone do not become confirmed preferences. Users can turn off Use my saved interests. This is explainable attribute transfer, not a learned persistent user embedding.

## Photo-region capture revision

The separate What matters to you section and editor were removed, returning the saved-product screen to its previous layout. In + → Photos, an attached photo now has Highlight a detail and a long-press shortcut. A dedicated sheet lets the user draw around a region. The app maps the drawing to normalized image coordinates, crops its rectangular bounds from the orientation-normalized original, shows the selected crop, and sends only that crop plus product-title context to the existing authenticated analysis relay. The original attachment is unchanged. Suggestions remain optional; the user selects or edits a preference and confirms Add this detail. Confirmed preferences feed the existing save, insights and recommendation path. Multiple details can be added by reopening the selector. Cancel does not modify the draft. Redrawing cancels the previous request and rejects stale responses; tiny selections show guidance; failed analysis permits manual text and retry.

This is manual region selection, not automatic object segmentation. Build and physical-device installation passed. A live crop of the user's Tudor dial returned HTTP 200 in 3.97 seconds and suggestions including the classic dial design and metallic dial finish. Physical drawing, scrolling, and confirmation still need user acceptance because remote touch control is unavailable.
