# Mymah Finds API contract

`openapi.json` is generated from FastAPI route/model definitions, contract version 0.2.0. Do not edit it manually. Run `make contracts`; `make test` checks drift.

The current Mymah Finds interface has **Library**, **Search**, and **Profile** only. Integrate identity (`/v1/me`), capabilities/content limits, capture, collection/detail reads, and deletion. Search operates on fetched saved content; the browser reference loads all collection pages and filters locally. There is no dedicated search endpoint. Coordinate complete-library search coverage with the backend owner.

The schema also retains annotation/evidence, discovery, catalog, watches, simulated observations, notifications, and diagnostic routes for later backend work. Their presence, or a true backend capability flag, does not make them required interface features. Do not connect them to the current navigation or display developer/demo diagnostics in product screens.

`examples/` contains isolated API responses generated by `make fixtures`. It covers capture/enrichment, future intelligence/commerce flows, and errors so existing contract behavior remains testable. Synthetic identifiers/timestamps change on regeneration. Fixture products, prices, and demo inference are not user-library content and must not be seeded into the interface as if the person saved them.

`clients/javascript/types.d.ts` is generated from the same schema. Swift models in `clients/ios/Sources/CommonThreadKit/Models.swift` are checked against copies of these fixtures. Update both clients for contract changes and preserve `/v1` compatibility where possible. Internal `CommonThread` SDK identifiers retain earlier names; the user-facing brand is Mymah Finds.

Read [the team handoff](../docs/team-handoff.md) for ownership, current acceptance criteria, capture state, account isolation, and retry recovery. `/v1/capabilities` remains the technical source for available backend operations and content limits, while the handoff defines which flows belong in the current interface.
